mumble-speechVideo-game mumble speech, generated at runtime

The babble that game characters speak, in three styles. One Rust core, the same output bit for bit on the web, in Godot, in Unity and from C.

Get started
Try the playground
GitHub

Beep

One beep for every letter, like Undertale.

Grunt

A few grunts per voice, never the same twice in a row, like Banjo-Kazooie.

Alphabet

A vowel-based sound for every letter, like Animal Crossing.

Typewriter dialogue

Ask for one character at a time and get its sound plus how long to wait before the next one.

Deterministic everywhere

Same text and voice, same samples, on Linux, Windows, macOS (Apple Silicon and Intel) and WebAssembly. Checked in CI with shared conformance vectors.

Nothing drawn for you

You get audio and timing data. What appears on screen is up to you; the playground is just one example.

Inspired by UnitOfTime's video I Gave My NPCs Voices Without Recording Anything.
